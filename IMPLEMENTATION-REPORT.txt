SEO PRESERVATION
Preserved case-sensitive content paths, PHP aliases, query variants, existing canonical strings, titles, descriptions, keywords, existing JSON-LD, original image alt text in retained content, source technical text and relevant internal links. The XML sitemap and robots file are unchanged copies. RSS and the search verification file are retained.

Canonical links are emitted as React resource links in the document head. This avoids Next.js Metadata normalization of the homepage trailing slash and two relative legacy canonical strings. CMS Open Graph settings are retained even where the old PHP templates did not emit them. Source Organization, LocalBusiness and FAQ schema is retained; supported WebSite, breadcrumb, Service, Product and Article data is added without invented offers, ratings or reviews. FAQ answers are also accessible in expandable content.

Existing index.php and trailing-slash permanent redirects are retained. Blog routes without a slug retain the listing redirect. There are no redirects to renamed business pages.

The original sitemap contains /images/certificate/3.pdf, which is absent locally and resolves to an unrelated directory index on the old site. An internal rewrite now serves the existing certificate3.pdf linked from the original About page at that public path. Certificate contents are unchanged, and no certification claims were inferred.

- Several original titles/OG titles are generic or inconsistent with their page. They were preserved rather than silently rewritten.

- Original backend form handlers, admin tools, mailer code and private uploads are not ported into the frontend.

HANDOVER
Run npm ci, then npm run dev from New/. Production commands are npm run build and npm run start. See README.md for content files, routes, audit regeneration and validation commands.

Hero video is intentionally disabled until the supplied asset exists. Add public/videos/exelcius-industrial-hero.mp4 and enable heroVideo in src/data/site.ts. The current fallback is a verified original workshop photograph, optimized by Next/Image; there is no missing-video network request.

The form requires a future separately scoped delivery integration to submit enquiries directly. The current email and WhatsApp alternatives are usable by the visitor.

No production deployment, DNS change, database import or modification of Previous/ or PPT/ was performed.
